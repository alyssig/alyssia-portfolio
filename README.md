# Alyssia Gaston - Portfolio

A single-page portfolio site for Alyssia Gaston, featuring software engineering,
game development, robotics, app development, experience, projects, skills, and
social links.

## Files
- `index.html` - all page content and sections
- `style.css` - all styling
- `script.js` - routing, particle art, carousel, experience tabs, Game Mode, and mini game

## How to deploy on Netlify
1. Go to https://app.netlify.com/drop
2. Drag this whole folder onto the page. No build command is needed.

You can also connect this GitHub repo to Netlify and deploy from the `main`
branch.

## To customize
- Edit the experiences, projects, and hardware arrays at the top of `script.js`
  to update rendered content.
- Edit `index.html` for static page content and section labels.
- Edit `style.css` for colors, spacing, layout, and responsive design.
- Game Mode toggle is top-left; it reskins the site and opens a small canvas
  mini game.
